# wcag-standards-mapping

Directed by Melanie Sumner Temple.
Generated by IBM Bob.

## What it does

This is supposed to map the Section 508 and EN 301 549 accessibility compliance standards to WCAG 2.2 Success Criteria.
The intent is to help people who are new to filling out Accessibility Compliance Reports (ACRs) using the VPAT template.

The HTML page itself has a filter/search function.

AI can make mistakes.
I'm still validating this data.

(No really, when it first generated the HTML page, there were over 900 accessibility issues.
With a lot of direction from a human with expertise, that number was reduced to zero.
At least, I think it's zero.
But I'm human, and I can make mistakes too.)
